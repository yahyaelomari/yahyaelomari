## What I've shipped

**Atos international portal** (VOID Agency, 2026)
Rebuilt the corporate portal of a ~100k-person company: decoupled Drupal 10 (JSON:API) and Next.js, 20 regions, 9 languages, 300+ concurrent editors. I delivered 3 of 7 content modules, a legacy-data migration pipeline, a reusable SEO module and a Playwright E2E suite. Lighthouse 91 / 94 / 92, 179 ms TTFB. I worked directly with the client's Product Owner.

**Amanti** (OpenTecc, 2025)
Designed a peer-to-peer last-mile delivery platform end to end: Spring Boot backend with RBAC and AOP audit logging, QR-code check-in/out, a native Shopify checkout plugin, Stripe payments and Next.js admin dashboards. Quality gates with SonarQube, JUnit and Mockito.

**[HealthPack](https://github.com/yahyaelomari/HealthPack)** (in progress)
Healthcare platform built as 15 Spring Boot microservices: REST, GraphQL and gRPC, Kafka and RabbitMQ, HL7 v2 and FHIR R4, signed PDFs, and a RAG assistant that only answers with citations. Built one service at a time.

**Agentic automations** (Ahdigital, 2025)
Built workflow automations in n8n: a social-intelligence "Competitive Watcher" (n8n, Supabase / Postgres and a React dashboard) that tracks competitors' activity, and a short-form content generation pipeline (n8n and Node.js) that turns an idea into a ready-to-post asset without manual steps.

**[manga-translate](https://github.com/yahyaelomari/manga-translate)**
Chrome/Brave extension that OCRs English speech bubbles on manga pages and shows hover translations. Manifest V3, Angular and client-side Tesseract.js.
